ORBITBILLS CAMERA FIX — QUICK APPLY
===================================

1. MERGE into your project:

   android/app/src/main/AndroidManifest.xml
   → add the three CAMERA lines under <manifest>

   android/app/src/main/java/com/techserenia/orbitbills/MainActivity.java
   → use the fixed MainActivity (or merge the WebChromeClient block)

2. Rebuild:

   npx cap sync android
   cd android && ./gradlew assembleDebug

3. Phone:

   Uninstall old APK → install new APK
   Billing → Scan → Camera scan → Allow

4. If still denied:

   Settings → Apps → OrbitBills → Permissions → Camera → Allow

Full details: APPLY_CAMERA_FIX.md
